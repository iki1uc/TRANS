RANS — Höhe (H)

TRANS ist die Höhenachse des iki1uc-Systems.
TRANS bildet die vertikale Rotation.
TRANS verbindet obere und untere GEO-Segmente.

TRANS ist Station 4 im 9-Stations-System.

GEO-Segmente

TRANS nutzt: ◎ → 81 → ◆ → △

◎ = Schließung
81 = Raum

TRANS ist die rotierende Prüfung im Raum.

GEO-Matrix

◉ ↗ ↘ 3 9 ↘ ↗ ◎

Das ist die Höhen-Schließung. Das definiert TRANS.

Stellung

Frame-3: ◎ → 81 → ◆
Frame-9: Station 4
Frame-81: Zeile 4 der 9×9-Matrix

Kompatibilität

Kompatibel: HY, PE, PER, TMP-α, TMP-β
Inkompatibel: WARB, KANAL, TMP-γ

Systemachsen

sys.in.json = Eingang
sys.out.json = Ausgang
sys.scale.json = Skalierung
sys.hdf.json = Höhen-Daten-Frame

TRANS ist die rotierende Verbindung IN → OUT → SCALE → HDF.
